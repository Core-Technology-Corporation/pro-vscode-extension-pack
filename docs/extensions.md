# Included extensions

## 🎨 Pro VSCode Themes
`alvarosiles.pro-vscode-themes`

Professional color themes designed for readability during long coding sessions.

- Repository: https://github.com/alvarosiles/pro-vscode-themes

## ⌨️ Pro VSCode Keybindings
`alvarosiles.pro-vscode-keybindings`

Productivity-focused keyboard shortcuts covering editing, git, debugging, explorer, and terminal actions.

- Repository: https://github.com/alvarosiles/pro-vscode-keybindings

## 🧩 Pro VSCode Snippets
`alvarosiles.pro-snippets`

Code snippets for JavaScript, TypeScript, HTML, CSS, and React to speed up everyday development.

- Repository: https://github.com/alvarosiles/pro-snippets

## 🛠 Pro VSCode Tools
`alvarosiles.pro-vscode-tools`

A set of developer utilities and commands for common editor tasks.

- Repository: https://github.com/alvarosiles/pro-vscode-tools

## 🤖 Pro VSCode AI
`alvarosiles.pro-vscode-ai`

AI-assisted chat, inline code edits, code review, and commit message generation, with support for multiple providers (Anthropic, OpenAI, Google, Ollama, LM Studio).

- Repository: https://github.com/alvarosiles/pro-vscode-ai
