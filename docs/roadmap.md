# Roadmap

Ideas and planned additions for the Pro VSCode ecosystem. Nothing here is guaranteed or scheduled — this is a running list of candidates.

## Possible future extensions

- **Pro VSCode Formatter** — opinionated formatting presets and pre-configured linters.
- **Pro VSCode Git Tools** — extended git workflow commands beyond the default keybindings.
- **Pro VSCode Icons** — a matching file icon theme for the Pro Themes.

## Pack improvements

- Add a settings sync profile so the pack can also apply recommended editor settings, not just extensions.
- Publish a banner image for the Marketplace listing.
